# AmberFlow

**Marketing site for AmberFlow painting courses** (Jawiszowice) — React + Vite + Tailwind portfolio and contact form for Weronika Ambrożkiewicz-Mosler.

Live: [amberflow.vercel.app](https://amberflow.vercel.app)

## Stack

- React 19, Vite, Tailwind CSS 4, lucide-react, Vercel Analytics

## Install & run

```bash
git clone https://github.com/biokineticum/amberflow.git
cd amberflow
npm install
npm run dev
```

Build / preview:

```bash
npm run build
npm run preview
```

Artwork images live under `public/images/`. Main UI: `src/App.jsx`.
